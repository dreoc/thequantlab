3D geometric morphometrics in R
GUImorph: a geomorph-native 3D digitizer

GUImorph places 3D landmarks and surface semilandmarks on scanned meshes, runs Generalized Procrustes Analysis, and passes the result straight to geomorph. It runs inside R, using a Tcl/Tk interface with an interactive OpenGL 3D view. This page walks a first-time user through the full workflow, one click at a time.

Geometric morphometrics turns the shape of an object into coordinates that can be measured and compared. For a Folsom point, that means recording the same anatomical landmarks and a dense set of surface points on every specimen, then aligning them so only shape differences remain. GUImorph is built to make that recording step approachable.

The need is concrete. In 2026, geomorph 4.1 removed its interactive 3D digitizing functions (digit.fixed, buildtemplate, digitsurface), because the newest macOS dropped OpenGL support and the underlying rgl graphics are no longer maintained there. A frozen copy of geomorph 4.0.9 remains on GitHub, unmaintained, for anyone with an older setup. GUImorph restores that template-based workflow as its own R package, and it writes data in the exact array format that geomorph's gpagen expects. No file conversion, and no separate application to install.

Windows: supported macOS: in progress
Which computer to use. Run GUImorph on Windows for now. The same OpenGL change that ended geomorph's digitizer also affects the 3D view on the newest macOS, so a browser-based version is planned for cross-platform use. Everything below assumes Windows.

What you will do

The workflow is a fixed sequence. Here is the whole thing at a glance, before the detailed steps.

  1. Install R and the GUImorph package.
  2. Prepare your PLY meshes (remove stray and origin points).
  3. Launch GUImorph and load your first specimen.
  4. Learn to rotate, zoom, and pan the 3D view.
  5. Place the fixed (anatomical) landmarks.
  6. Place anchors or curve points, if your protocol uses them.
  7. Build the surface template once, on a reference specimen.
  8. Apply the template to every other specimen.
  9. Save each specimen to a .dgt file.
  10. Merge the .dgt files into one dataset.
  11. Run GPA and inspect the results.
  12. Hand the coordinates to geomorph.

Part 1 · Before you start

Install R

GUImorph runs inside R. If you do not have it, install R from the official site, and optionally RStudio as a friendlier console. Any recent version of R for Windows works.

Get itDownload R for Windows from cran.r-project.org. Install with the default options.

Install the GUImorph package

Use the prebuilt Windows package. This is the simplest path and needs no compiler. Save the package file somewhere you can find it, then run the command below in the R console, editing the path to match where you saved it.

# Install GUImorph on Windows (prebuilt package).
# Edit the path to wherever you saved the file.
install.packages("C:/Users/you/Downloads/GUImorph_1.0.0.zip", repos = NULL)

# Load it. Do this once at the start of every session:
library(GUImorph)
It worked if library(GUImorph) returns to the prompt with no red error text.
Building from source (advanced)

If you were given the source folder instead of a prebuilt package, you can compile it, but this requires a C toolchain to build the OpenGL engine.

install.packages("C:/path/to/GUImorph", repos = NULL, type = "source")

Build the C component with Visual Studio 2022 Build Tools and CMake. Do not compile it with MinGW or the default gcc from Rtools for this part. That toolchain renders the mesh solid black. If your specimen shows up as a featureless black shape, this is almost always the cause.

Prepare your meshes

GUImorph reads PLY surface files. Export your scans as .ply with per-vertex color kept. Before digitizing, remove junk points from each mesh. Scanner exports (for example from NextEngine or ScanStudio) usually carry unreferenced vertices that belong to no face, and null vertices sitting at the exact origin, the point (0, 0, 0). These points are invisible while you work, but they land far from your specimen and become extreme outliers once you run GPA. One uncleaned mesh can distort the alignment of the whole dataset.

Do thisIn MeshLab, open each mesh and run Filters ▸ Cleaning and Repairing ▸ Remove Unreferenced Vertices, then Remove Duplicate Vertices. Delete any vertex sitting at the origin. Keep all faces and colors. Export back to .ply.
Common mistake

Skipping this step. It is the single most frequent reason one specimen looks wildly wrong in the final plot. If a point cloud or mesh includes a vertex at exactly (0, 0, 0), remove it before you digitize.

Part 2 · The digitizing workflow

Work through these in order. Each step tells you what to do, and how to tell it worked.

1

Launch GUImorph

With the package loaded, open the interface from the R console.

library(GUImorph)
GUImorph()

A window opens with a menu bar across the top and a large dark panel. That dark panel is the 3D view. It is empty until you load a specimen.

The GUImorph window is open and you can see the File menu.
2

Load your first specimen

Open one of your cleaned meshes.

MenuFile ▸ Add PLY, then choose one of your .ply files.

Your specimen appears in the 3D view, in its scanned color. If it looks small or off-center, that is fine. You will orient it in the next step.

Your specimen is visible in the 3D panel.
3

Move the 3D view

Before placing any points, learn to move the specimen so the region you want to landmark faces you. The view controls are mouse-driven.

RotateHold the left mouse button and drag.
ZoomScroll the mouse wheel in and out.
PanHold the right mouse button and drag to slide the specimen sideways.
Tip

Rotating the specimen does not move the landmarks you have already placed. They stay locked to the surface. Turn the specimen freely to check your points from every angle.

You can turn, zoom, and slide the specimen at will.
4

Place the fixed landmarks

Fixed landmarks are your numbered anatomical points, the same points in the same order on every specimen. This defined order is what lets you compare specimens later, so decide your landmark scheme first and follow it exactly.

StartEnter fixed-landmark mode (the digitize control), then left-click directly on the surface at each landmark, in order: 1, 2, 3, and so on.

A marker drops onto the surface at each click. The marker sits slightly above the mesh so it is easy to see and does not disappear into the surface.

UndoTo remove the last point you placed, delete it and click again. Placing points in the correct order matters more than placing them quickly.
Tip

Zoom in before clicking a precise landmark. A point placed while zoomed out can be off by more than you expect. Rotate the specimen afterward to confirm the marker sits exactly where you intended.

All fixed landmarks are placed, numbered in order, each sitting on the surface.
5

Place anchors or curve points

Some protocols add anchors, points along an edge or ridge that guide where the surface points go. If your scheme does not use them, skip this step.

Do thisSwitch to anchor mode, then left-click along the feature to mark it. Use the same anchors on every specimen.
Your anchors trace the same feature you will trace on the other specimens.
6

Build the surface template (once)

Surface semilandmarks are a dense grid of points spread over the surface between your fixed landmarks. To make them correspond across specimens, you first build a template on one good reference specimen. You do this a single time for the whole study.

Do thisWith the reference specimen loaded and its fixed landmarks placed, run the build-template step. When asked, enter how many surface points you want. GUImorph spreads that many points over the surface and saves a file named template.txt in your working folder.
What the template is for

The template records the pattern of surface points on the reference. Every other specimen will receive the same pattern, warped to fit its own surface, so point number 50 means the same location on every specimen. This follows the method of Gunz, Mitteroecker and Bookstein (2005), the same approach geomorph used.

A template.txt file exists in your folder, and surface points cover the reference specimen.
7

Apply the template to every other specimen

Now digitize the rest of your specimens. Each one gets its fixed landmarks first, then the surface points come from the template automatically.

Repeat per specimenLoad the next specimen with File ▸ Add PLY. Place the same fixed landmarks in the same order. Then run the surface step. GUImorph aligns the template to this specimen and drops the surface points into their corresponding places.
Give it a moment when switching specimens

When you move to a new specimen, GUImorph re-sends the surface data to the 3D engine, which clears it on each load. A brief pause after loading is normal.

Each specimen ends with the same number of surface points as the template, in matching positions.
8

Save each specimen

Save every specimen as you finish it. Do not wait until the end.

MenuFile ▸ Save. This writes a .dgt file holding that specimen's landmark coordinates. Name the file after the specimen so you can tell them apart.
You have one .dgt file per specimen, clearly named.
9

Merge the specimen files

Combine your individual .dgt files into one dataset that holds every specimen together.

MenuFile ▸ Merge DGT, then select all of your .dgt files at once.
One merged dataset now contains all specimens, ready for analysis.
10

Run GPA

Generalized Procrustes Analysis removes differences in position, rotation, and size, so that only shape remains. This is the step that makes specimens comparable.

Do thisOpen the GPA panel and run the analysis on your merged dataset.
GUImorph reports aligned coordinates and a mean shape.
11

Inspect the results

Use the plotting buttons to check your work before moving on.

Specimensplotspecs shows every specimen overlaid, so you can spot one that is misaligned.
MeanplotMeanShape shows the average shape of the sample.
VariationplotPCA places specimens on principal component axes, so you can see how they spread.
Reading the PCA

If one specimen sits far away from all the others in the PCA plot, that is usually a mesh-cleaning miss, an unreferenced or origin vertex that survived. Go back, re-clean that mesh, and re-digitize it if needed.

Specimens overlay sensibly, and no point sits impossibly far from the rest.
12

Take it into geomorph

This is the payoff. GUImorph's coordinates are already in the three-dimensional array format that geomorph's gpagen reads, so there is no conversion step and no export to another program.

library(geomorph)

# 'coords' is the landmark array from your merged GUImorph dataset.
gpa <- gpagen(coords)
plot(gpa)

# From here, the full geomorph toolkit is available:
# principal components, allometry, Procrustes ANOVA, and more.
gpagen runs without a shape error, and your analysis continues in geomorph.

Part 3 · Troubleshooting

The package will not load, or cannot find tkogl2.dll

On 64-bit Windows, an older build could fail to locate its OpenGL engine file. Install the current GUImorph package, which corrects the file path it searches. If you built from source, rebuild and reinstall.

The specimen shows up as a solid black shape

The OpenGL engine was compiled with the wrong toolchain. Use the prebuilt package, or rebuild the C component with Visual Studio 2022 Build Tools and CMake. MinGW and the default gcc produce a black mesh.

One specimen is a wild outlier in the PCA

Almost always a cleaning miss. Reopen that mesh, remove unreferenced vertices and any vertex at the origin (0, 0, 0), and re-run. See Prepare your meshes.

Clicking the mesh does nothing

Check which mode you are in. You must be in fixed-landmark, anchor, or surface mode before a click registers as a point. Rotating and clicking are separate actions.

The 3D window will not open on my Mac

Expected on the newest macOS. The OpenGL support GUImorph relies on for the 3D view was removed there, which is the same change that retired geomorph's own digitizer. Use Windows for now. A browser-based version is planned for full cross-platform support.
